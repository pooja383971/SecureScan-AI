# SecureScan-AI

A Full Stack Vulnerability Scanner built using React.js, Spring Boot, Java 17, MySQL, JWT Authentication, OWASP Dependency Check and Nmap.

## Features

- User Registration & Login
- JWT Authentication
- Dashboard
- Website & Network Scanning
- OWASP Dependency Check Integration
- Nmap Integration
- Vulnerability Reports
- Scan History
- PDF Report Generation
- Responsive UI

## Technology Stack

### Frontend
- React.js
- Bootstrap
- JavaScript
- HTML5
- CSS3

### Backend
- Spring Boot
- Java 17
- Spring Security
- JWT
- REST API

### Database
- MySQL
- Spring Data JPA
- Hibernate

### Scanner
- OWASP Dependency Check
- Nmap

## Installation

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Database

```sql
CREATE DATABASE securescan_db;
```
